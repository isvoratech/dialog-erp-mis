# Dialog ERP MIS

Dialog ERP MIS is a full-stack internal management information system with a Java backend, Angular frontend, Python calculation service, infrastructure configuration, and deployment support.

## Project structure

- `backend-java/` — Java backend service
- `frontend-angular/` — Angular frontend
- `calc-python/` — Python calculation and test components
- `infra/` — infrastructure and deployment configuration
- `docker-compose.yml` — local/container orchestration

## Security

Production secrets, environment files, compiled artifacts, logs, database dumps, backups, virtual environments, Node modules, and build outputs are intentionally excluded from version control.
